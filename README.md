\# Realistická interaktivní simulace v Unreal Engine 5



\## O projektu



Tento projekt vzniká jako dlouhodobá praktická maturitní práce

na Střední průmyslové škole Mladá Boleslav.



Cílem je vytvořit realistickou interaktivní simulaci z pohledu

první osoby v prostředí Unreal Engine 5.



Vizuální zpracování je inspirováno stylem hry Bodycam.



Simulace bude představovat blíže neurčené válečné prostředí

s opuštěnými a částečně poškozenými budovami, místnostmi,

chodbami a dalšími zákoutími.



\## Hlavní cíle projektu



\- Vytvoření realistického 3D prostředí.

\- Implementace ovládání postavy z první osoby.

\- Systém interakce pomocí Blueprintů.

\- Realistické osvětlení a materiály.

\- Zvukové efekty a nastavení kamery.

\- Interaktivní prvky prostředí.

\- Optimalizace výkonu.

\- Testování a dokumentace výsledné aplikace.



\## Použité technologie



\- Unreal Engine 5

\- Blueprints

\- Git

\- GitHub

\- Git LFS



\## Verzování projektu



Projekt využívá Git pro správu historie změn

a Git LFS pro verzování velkých binárních souborů.



Soubor `.gitignore` vylučuje nepotřebné generované soubory

Unreal Engine z verzování.



\## Stav projektu



Projekt je ve fázi přípravy a zakládání vývojového prostředí.
